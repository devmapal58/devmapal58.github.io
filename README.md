# Личный сайт Ильи — devmapal58

Отдельный публичный статический сайт. Это не копия серверного дашборда.

- `/` — визитка инженера-самоучки: кассы, компьютерная техника и практический ИИ.
- `/course/` — публичная точка входа в отдельный закрытый учебный раздел на VPS. Пароль проверяет сервер, не JavaScript GitHub Pages. Доступ к курсу не должен давать доступ к управлению дашбордом.
- `style.css` — общая тема Blaugrana и встроенный Manrope из личного дашборда.
- `FONT-LICENSE.txt` — SIL Open Font License.

## Проверка

```sh
node --test tests/site.test.cjs
```

Сайт не использует сборщик, сторонние скрипты или внешние шрифты. GitHub Pages публикует статические файлы из корня `main`; `.nojekyll` отключает обработку Jekyll.

## Что нельзя публиковать

Не добавлять в этот репозиторий серверный код и конфиги дашборда, базы/JSON с задачами, исходные учебные материалы и комментарии, видео, OAuth/cookies, пароли, htpasswd и приватные ключи. Закрытая читалка курса и её данные разворачиваются отдельно на VPS, под серверной проверкой доступа.

Изменение ссылки на курс не означает развёртывания защиты: перед публикацией проверять 401 без пароля на HTML, JSON и вложенных файлах курса, а также невозможность использовать пароль курса для API дашборда.
